# Gear data sources

The pilot Gear catalog was compared on 2026-08-04 against:

- the supplied Horde and Alliance Classic Era level-19 workbook;
- Jamesb's 19 Vanilla Gearing Guide on XPOff;
- Wowhead's Classic level-19 class guides;
- Warcraft Tavern's Classic level-19 class guides and twinking overview;
- Wow Classic BiS level-19 class pages for cross-checking slot candidates.

Tier S is the primary competitive recommendation in the current pilot. Tiers A
and B represent role, faction, availability, random-suffix or budget options.
They are not a universal mathematical ranking for every WSG composition.

Faction-equivalent rewards remain distinct items. Where Classic Era provides no
verified competitive third item (notably the level-19 neck slot), the UI states
that explicitly instead of importing a TBC/SoD item or inventing an alternative.
